Install rust 1.90.0, it will probobly work on other versions but thats what I have it set to, then while in this folder just run make.
You also have the option to run "cargo run" to run it or "cargo build" to build it in the target folder. All make does is build it then copy the executable file to the main folder.
I made this on linux so it should work on the lab machines, but due to how I handled envirnement valariables it will only work on windows when running something like wsl.
